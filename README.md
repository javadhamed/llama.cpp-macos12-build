# llama.cpp macOS 12 Build

Custom build of llama.cpp for macOS 12 compatibility with Hy-MT2 1.25-bit GGUF support.

## ⭐ Support / حمایت

---

⭐ **If you found this project useful, please give it a star!** It helps others discover it and motivates continued development.

**What it does:** Custom build of llama.cpp for macOS 12 compatibility, including Hy-MT2 1.25-bit GGUF support.
**Why it exists:** To enable running modern LLMs and translation models on older Intel-based macOS versions where official builds may fail.

**کارایی:** بیلد اختصاصی llama.cpp برای سازگاری با macOS 12، شامل پشتیبانی از GGUF 1.25 بیتی Hy-MT2.
**دلیل ساخته شدن:** برای فعال‌سازی اجرای LLMهای مدرن و مدل‌های ترجمه در نسخه‌های قدیمی‌تر macOS مبتنی بر اینتل که بیلدهای رسمی ممکن است در آن‌ها با خطا مواجه شوند.
